# NovaAI — Site Premium com IA

Projeto de site premium com visual moderno, animações, login/cadastro, planos, suporte e área para chat com IA.

## Arquivos
- `index.html` → página principal
- `styles.css` → estilos visuais
- `app.js` → interações do site
- `server.js` → backend com login, cadastro, tickets e IA
- `package.json` → dependências do servidor
- `.env.example` → variáveis de ambiente
- `data/db.json` → banco local simples

## Funcionalidades
- Design premium e responsivo
- Botões animados
- Login e cadastro
- Planos de assinatura
- Suporte por ticket
- Chat com IA
- Estrutura pronta para crescer

## Como usar

### Versão estática
Se você for publicar no GitHub Pages, use:
- `index.html`
- `styles.css`
- `app.js`

### Versão completa
Se quiser login, cadastro e IA funcionando de verdade, rode o backend:

```bash
npm install
npm start
